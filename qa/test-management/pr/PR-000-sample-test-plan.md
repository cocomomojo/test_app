## 1. 変更概要

### 何を変更したか

- TODO を完了にした際、一覧上に完了日時を表示する
- 完了済み TODO を再度未完了に戻した場合、完了日時をクリアする
- 完了状態のUI表示を少し調整する

### 変更理由

- ユーザーが「いつ完了したか」を画面上で確認できるようにするため
- 運用上、完了タイミングの確認ニーズがあったため

### 影響範囲

- [x] Frontend
- [x] Backend
- [x] API
- [ ] DB
- [ ] Infra / CI
- [ ] Docs / Manual

## 5. 実施予定テスト項目

### ☕ Backend Unit / Integration

- [ ] TODO完了時に `completedAt` が設定されること
- [ ] TODOを未完了へ戻した時に `completedAt` が `null` になること
- [ ] 更新APIレスポンスに `completedAt` が含まれること

### 🖥️ Frontend Unit / Component

- [ ] 完了済み TODO に完了日時が表示されること
- [ ] 未完了 TODO に完了日時が表示されないこと
- [ ] 完了 → 未完了切り替え時に表示が消えること

### 🎭 E2E

- [ ] TODOを完了にした時、一覧で完了日時が表示されること
- [ ] TODOを未完了に戻した時、完了日時表示が消えること

### 👤 Manual / UAT

- [ ] 完了日時の表示位置が見やすいこと
- [ ] 日時フォーマットが利用者にとって理解しやすいこと
