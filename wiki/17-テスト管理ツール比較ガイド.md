## 🤔 テスト管理ツールとは？

テスト管理ツールは、**テストケースの作成・管理・実行・レポート**を一元化するツールです。

```
📝 テストケース作成 → 🔄 テスト実行 → 📊 結果レポート → 🐛 バグ管理
```

## 📝 各ツール詳細

### 1️⃣ TestRail（テストレール）

> 🏆 **業界標準のテスト管理ツール**

```
💡 キャッチフレーズ：「プロフェッショナルなテスト管理の定番」
```

#### ✅ メリット

| 項目 | 説明 |
|:-----|:-----|
| 🎯 直感的なUI | ドラッグ&ドロップでテストケース管理が簡単 |
| 📊 豊富なレポート | グラフ・チャートで進捗が一目瞭然 |
| 🔗 CI/CD連携 | Playwright, JUnitとの連携が容易 |
| 📱 REST API | 自動化テスト結果の自動取り込み |
| 👥 チーム管理 | 役割別のアクセス権限設定 |

#### ❌ デメリット

| 項目 | 説明 |
|:-----|:-----|
| 💰 コスト | 月額$32～/ユーザー（チームが大きいと高額） |
| 🔧 カスタマイズ | 高度なカスタマイズには技術知識が必要 |
| 📦 オンプレミス | クラウド版は制限あり |

#### 🔄 構成との相性

```
✅ Vitest/JUnit → TestRail API連携で自動レポート
✅ Playwright → testrail-reporterで結果自動送信
✅ 手動テスト → Webブラウザから実行・記録
```

#### 🔍 SonarQubeとの親和性

| 連携項目 | 対応レベル | 説明 |
|:--------|:----------|:-----|
| 静的解析結果連携 | ✅ 優秀 | REST APIで品質ゲート結果を自動取り込み |
| 品質メトリクス統合 | ✅ 優秀 | カスタムフィールドでCode Coverage、Technical Debt表示 |
| CI/CD統合 | ✅ 優秀 | SonarQube品質ゲート通過後にテスト実行トリガー |
| 欠陥トレーサビリティ | ✅ 優秀 | SonarQube Issues ↔ TestRail Defectsの双方向リンク |
| SonarQube-mcp連携 | ✅ 良好 | 自動修正後のリグレッションテスト自動実行 |

**実装例:**
```javascript
// TestRail + SonarQube 連携
const sonarResults = await getSonarQubeResults(projectKey);
if (sonarResults.qualityGate.status === 'OK') {
  await testRail.triggerTestRun({
    name: `Code Quality Verified - ${sonarResults.analysisDate}`,
    suiteId: regressionSuiteId
  });
}
```

#### 🔍 SonarQubeとの親和性

| 連携項目 | 対応レベル | 説明 |
|:--------|:----------|:-----|
| 静的解析統合 | ⭐ 最高 | GitHub Actions + SonarCloudで完全統合 |
| 品質ゲート連動 | ⭐ 最高 | SonarQube品質ゲート失敗時に自動でIssue作成 |
| CI/CD統合 | ⭐ 最高 | 同一リポジトリ内でコード品質とテスト品質を一元管理 |
| SonarQube-mcp連携 | ⭐ 最高 | 自動修正 → テスト更新 → PR作成の完全自動化 |
| メトリクス統合 | ⭐ 最高 | Code Coverage + Test Coverage統合ダッシュボード |

**完全統合ワークフロー例:**
```yaml
name: Quality + Test Integration
on: [push, pull_request]

jobs:
  sonarqube-analysis:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: SonarQube Analysis
        uses: sonarqube-quality-gate-action@master
        env:
          SONAR_TOKEN: ${{ secrets.SONAR_TOKEN }}

  test-execution:
    needs: sonarqube-analysis
    if: ${{ needs.sonarqube-analysis.outputs.quality-gate-status == 'PASSED' }}
    runs-on: ubuntu-latest
    steps:
      - name: Run Tests
        run: npm test
      - name: Update Test Documentation
        run: |
          echo "## 🔍 Quality Gate: PASSED" >> test-results/quality-report.md
          echo "- Coverage: ${{ steps.sonar.outputs.coverage }}%" >> test-results/quality-report.md

  sonar-mcp-auto-fix:
    if: ${{ needs.sonarqube-analysis.outputs.quality-gate-status == 'FAILED' }}
    runs-on: ubuntu-latest
    steps:
      - name: Auto-fix with SonarQube MCP
        run: |
          mcp-client sonarqube-mcp fix-issues --project-key=${{ github.repository }}
      - name: Update Test Cases
        run: |
          # 自動修正に対応するテストケース更新
          ./scripts/update-test-cases.sh
      - name: Create PR
        run: |
          gh pr create --title "Auto-fix: SonarQube Issues + Test Updates" \
                       --body "Automated fixes with corresponding test updates"
```

##### 3-2. テストメトリクス収集

**`scripts/collect-test-metrics.js`**
```javascript
const fs = require('fs');
const path = require('path');

// テストケースファイルを分析
const analyzeTestCases = () => {
  const testDirs = ['tests/unit', 'tests/e2e', 'tests/manual'];
  const metrics = {
    totalTests: 0,
    testsByCategory: {},
    testsByPriority: {},
    updatedRecently: 0
  };

  testDirs.forEach(dir => {
    if (fs.existsSync(dir)) {
      const files = fs.readdirSync(dir, { recursive: true });
      files.filter(file => file.endsWith('.md')).forEach(file => {
        const content = fs.readFileSync(path.join(dir, file), 'utf8');
        metrics.totalTests++;

        // カテゴリ別集計
        const category = dir.split('/').pop();
        metrics.testsByCategory[category] = (metrics.testsByCategory[category] || 0) + 1;

        // 優先度別集計
        const priorityMatch = content.match(/優先度\*\*:\s*(High|Medium|Low)/);
        if (priorityMatch) {
          const priority = priorityMatch[1];
          metrics.testsByPriority[priority] = (metrics.testsByPriority[priority] || 0) + 1;
        }

        // 最近更新されたかチェック
        const updateMatch = content.match(/最終更新\*\*:\s*(\d{4}-\d{2}-\d{2})/);
        if (updateMatch) {
          const updateDate = new Date(updateMatch[1]);
          const weekAgo = new Date(Date.now() - 7 * 24 * 60 * 60 * 1000);
          if (updateDate > weekAgo) {
            metrics.updatedRecently++;
          }
        }
      });
    }
  });

  return metrics;
};

// メトリクスをMarkdown形式で出力
const metrics = analyzeTestCases();
console.log('# 📊 Test Metrics Report');
console.log('');
console.log(`**Total Test Cases**: ${metrics.totalTests}`);
console.log('');
console.log('## 📋 By Category');
Object.entries(metrics.testsByCategory).forEach(([category, count]) => {
  console.log(`- ${category}: ${count}`);
});
console.log('');
console.log('## 🚨 By Priority');
Object.entries(metrics.testsByPriority).forEach(([priority, count]) => {
  console.log(`- ${priority}: ${count}`);
});
console.log('');
console.log(`**Recently Updated**: ${metrics.updatedRecently} test cases in the last 7 days`);
```

```javascript
          property: 'Execution Date',
          date: {
            after: oneWeekAgo.toISOString().split('T')[0]
          }
        },
        {
          property: 'Result',
          select: {
            is_not_empty: true
          }
        }
      ]
    }
  });

  // 統計情報を計算
  const stats = {
    total: executedTests.results.length,
    passed: 0,
    failed: 0,
    blocked: 0,
    byCategory: {}
  };

  executedTests.results.forEach(test => {
    const result = test.properties.Result.select?.name;
    const category = test.properties.Category.select?.name;

    if (result === 'Pass') stats.passed++;
    else if (result === 'Fail') stats.failed++;
    else if (result === 'Blocked') stats.blocked++;

    if (category) {
      stats.byCategory[category] = (stats.byCategory[category] || 0) + 1;
    }
  });

  // レポートページを作成
  const reportPage = await notion.pages.create({
    parent: { database_id: process.env.NOTION_DATABASE_ID },
    properties: {
      'Test Name': {
        title: [
          {
            text: {
              content: `Weekly Test Report - ${new Date().toLocaleDateString()}`
            }
          }
        ]
      },
      'Category': {
        select: {
          name: 'Report'
        }
      }
    },
    children: [
      {
        object: 'block',
        type: 'heading_2',
        heading_2: {
          rich_text: [
            {
              text: {
                content: '📊 Weekly Test Summary'
              }
            }
          ]
        }
      },
      {
        object: 'block',
        type: 'paragraph',
        paragraph: {
          rich_text: [
            {
              text: {
                content: `Total Executed: ${stats.total}\nPassed: ${stats.passed}\nFailed: ${stats.failed}\nBlocked: ${stats.blocked}\nPass Rate: ${((stats.passed / stats.total) * 100).toFixed(1)}%`
              }
            }
          ]
        }
      }
    ]
  });

  console.log('Weekly report created:', reportPage.url);
}

generateWeeklyReport().catch(console.error);
```
