# 単体テスト

## 概要
このリポジトリでは、Backend は JUnit + Mockito、Frontend は Vitest + Vue Test Utils を使って単体テストを実行します。
カバレッジは **80% 以上** を目標に設定しています。

---

## Backend（Spring Boot）

### 実行方法（Docker 推奨）
ホストに Java を入れずに実行できます。

```bash
# backend テスト + JaCoCo レポート
cd test_app

docker run --rm \
  -v "$PWD/backend:/app" \
  -w /app \
  test-app-backend-builder \
  ./gradlew test jacocoTestReport
```

### レポート出力
- HTML: `backend/build/reports/jacoco/test/html/index.html`
- XML: `backend/build/reports/jacoco/test/jacocoTestReport.xml`

### カバレッジ閾値
- `backend/build.gradle` にて **INSTRUCTION 80%** を設定

---

## Frontend（Vue）

### 実行方法（Docker 推奨）
Node 環境をホストに入れずに実行できます。

```bash
# 依存インストール
cd test_app

docker run --rm \
  -v "$PWD/frontend:/app" \
  -w /app \
  node:18 \
  npm install

# 単体テスト + カバレッジ
cd test_app

docker run --rm \
  -v "$PWD/frontend:/app" \
  -w /app \
  node:18 \
  npm run test:unit
```

### レポート出力
- HTML: `frontend/coverage/index.html`
- JSON: `frontend/coverage/coverage-final.json`

### 注意点
- Vitest は **E2E テストを除外**して unit のみ実行
- Vuetify の警告が出る場合がありますが、テスト結果には影響しません

---

## よくあるトラブル

- **Java がない**: Backend テストは Docker で実行してください
- **E2E が混ざる**: `npm run test:unit` を使用してください
