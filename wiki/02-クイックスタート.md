## 🐳 Docker Compose を使用した起動（推奨）

最も簡単で、すべてのサービスが自動的に起動します。

### 1. サービスの起動

```bash
# プロジェクトルートから移動
cd infra

# ローカル開発用の docker-compose を実行
docker compose -f docker-compose.local.yml up -d --build
```

**起動されるサービス：**

| サービス | ポート | 説明 |
|---------|--------|------|
| 🍃 Backend (Spring Boot) | 8080 | メインアプリケーション |
| 🖖 Frontend (Vite dev server) | 5173 | 開発サーバー |
| 🗄️ MySQL | 3306 | リレーショナルデータベース |
| ☁️ LocalStack (S3 Mock) | 9000 | ローカル S3 シミュレータ |

### 2. 動作確認

```bash
# コンテナの状態を確認（すべて Up になるまで待つ）
docker compose -f docker-compose.local.yml ps

# Backend の Health Check
curl http://localhost:8080/actuator/health

# レスポンス例：
# {"status":"UP","components":{"db":{"status":"UP"}}}
```

### 3. ブラウザでアクセス

```
Frontend: http://localhost:5173
Backend API: http://localhost:8080/api
H2 DB Console: http://localhost:8080/h2-console（開発用）
```

**ブラウザで http://localhost:5173 を開き、ログインページが表示されることを確認します。**

### 4. ログの確認

```bash
# すべてのサービスのログを表示
docker compose -f docker-compose.local.yml logs

# Backend のログのみ表示（最新 200 行）
docker compose -f docker-compose.local.yml logs backend --tail=200

# リアルタイムでログを追跡
docker compose -f docker-compose.local.yml logs -f backend

# Frontend のログを表示
docker compose -f docker-compose.local.yml logs frontend
```

### 5. サービスの停止

```bash
# サービスを停止
cd infra
docker compose -f docker-compose.local.yml down

# ボリューム（データベースデータ）も削除する場合
docker compose -f docker-compose.local.yml down -v

# イメージも削除する場合
docker compose -f docker-compose.local.yml down -v --rmi all
```

## 💻 Docker を使わない実行（開発者向け）

### Backend の起動（Spring Boot）

```bash
cd backend

# Gradle Wrapper を使用して起動
./gradlew bootRun

# 別方法：JAR ファイルをビルルして実行
./gradlew bootJar
java -jar build/libs/test-app-*.jar --spring.profiles.active=local
```

**要件：**
- Java 21 以上
- MySQL 8.0（ローカルで実行中または docker run で起動）
- Gradle（または gradlew を使用）

### Frontend の起動（Vue.js + Vite）

```bash
cd frontend

# 依存関係をインストール
npm install

# 開発サーバーを起動
npm run dev

# ブラウザで http://localhost:5173 にアクセス
```

**要件：**
- Node.js 18 以上
- npm または yarn

## 🧪 E2E テストの実行

### Playwright テストの実行

```bash
cd frontend

# 依存関係をインストール（初回）
npm install

# Playwright ブラウザをインストール（初回）
npm run setup:e2e

# 公式 Playwright Test Agents を初期化（初回 1 回）
# planner / generator / healer を使う場合に必要
npm run setup:agents

# テストを実行（Headed モード：ブラウザが表示される）
npm run test

# テストを実行（Headless モード：バックグラウンド実行）
npm run test:headless

# 特定のテストを実行
npx playwright test tests/e2e/login.spec.ts

# テストレポートを表示
npx playwright show-report
```

### Allure レポートの生成

```bash
cd frontend

# テストを実行して Allure レポートを生成
npm run test:allure

# レポートを表示
npx allure serve allure-results
```

## 🔧 トラブルシューティング

### ポートが既に使用されている

```bash
# ポート 8080 が使用されているかを確認（Linux/Mac）
lsof -i :8080

# Windows の場合
netstat -ano | findstr :8080

# ポートを解放する場合
kill -9 <PID>  # Linux/Mac
taskkill /PID <PID> /F  # Windows
```

### MySQL 接続エラー

```bash
# MySQL コンテナのログを確認
docker compose -f docker-compose.local.yml logs mysql

# MySQL が起動していることを確認
docker exec -it $(docker ps -q -f ancestor=mysql:8.0) mysql -u root -ptest123 -e "SELECT 1;"
```

### Frontend ビルドエラー

```bash
# キャッシュをクリア
rm -rf frontend/node_modules frontend/package-lock.json

# 再度インストール
cd frontend
npm install
npm run dev
```

### Docker デーモンが起動していない

```bash
# Linux の場合
sudo systemctl start docker

# Mac または Windows は Docker Desktop を起動
```
